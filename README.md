# Fennec

A Next.js frontend for the Fennec project, providing an intuitive UI for blockchain interactions and analytics.

## Installation & Running

### Clone the Repository

```bash
git clone https://github.com/alwazaamir/Fennec.git
cd fennec
```

### Using Yarn

```bash
yarn install

yarn dev
```

### Using npm

```bash
npm install

npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
